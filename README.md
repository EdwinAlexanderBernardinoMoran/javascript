# 🚀 Mi aprendizaje de JavaScript

Este repositorio documenta mi progreso en el aprendizaje de **JavaScript Moderno**. Aquí recopilo conceptos fundamentales, ejercicios prácticos y ejemplos que demuestran competencias en:

- Sintaxis moderna (let/const, arrow functions, destructuring)
- Programación asíncrona (Promises, async/await)
- Módulos ES6
- Métodos de arrays modernos
- DOM manipulation y eventos
- Fetch API y manejo de datos

El objetivo es construir una base sólida en el desarrollo web actual con JavaScript

## 📝 Resumen ejecutivo

A través de este curso he aprendido a escribir código más limpio, moderno y eficiente utilizando las características actuales de JavaScript. Incluye ejemplos prácticos sobre programación funcional, asincronismo, manipulación avanzada de arreglos, objetos, módulos, clases y manejo de APIs. Los ejercicios están desarrollados utilizando **Vite** como herramienta de desarrollo, lo que permite un entorno ágil con recarga en caliente y configuración mínima. También se incluyen ejercicios que fortalecen la comprensión de conceptos como callbacks, promesas, async/await, closures, desestructuración y más.

## 🎯 Objetivos de aprendizaje

- Comprender a profundidad la evolución de JavaScript moderno y sus bases.
- Usar `let, const, arrow functions, template strings y módulos`.
- Dominar métodos modernos de arreglos y manipulación de datos.
- Trabajar con asincronía: `callbacks, promesas, async/await`.
- Organizar código en módulos reutilizables.
- Implementar programación funcional aplicada.
- Consumir APIs REST de forma limpia y robusta.
- Manejar errores correctamente y escribir código más seguro.
- Aplicar buenas prácticas de estilo, legibilidad y arquitectura.

## 🧠 Conceptos y habilidades

**Arreglos avanzados**:

- map, filter, reduce, find, some, every, sort

**Objetos y estructuras modernas**:

- desestructuración, parámetros REST, spread operator, objetos literales

**Funciones modernas**:

- arrow functions, callbacks, closures, funciones puras

**Asincronismo**:

- promesas, async/await, Fetch API, manejo de errores con try/catch

**Módulos ES6**:

- import/export, organización del código

**Clases**:

- métodos, constructores, herencia, super

**Buenas prácticas**:

- código declarativo, funciones puras, legibilidad, principios DRY
